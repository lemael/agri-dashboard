🌿 Facilitar Dashboard

Plateforme de gestion commerciale et financière pour l'agriculture — commandes, ventes, producteurs, comptabilité et agents terrain.

React + Vite Node.js + Express PostgreSQL (prod) SQLite (local) Railway

Présentation générale

Facilitar est une application web multi-rôles qui centralise la gestion commerciale et financière d'une filière agricole.

📦

Commandes

Suivi des commandes grossistes et revendeurs avec gestion des statuts en temps réel.

🌾

Ventes terrain

Catalogue des ventes disponibles par producteur, avec prix, quantités et localisation.

👨‍🌾

Producteurs

Annuaire complet des producteurs avec leurs exploitations et coordonnées.

💰

Comptabilité

Tableau de bord financier : CA, dépenses, résultat net, paiements, commissions agents.

📱

Call Center

Espace personnel pour les agents terrain : profil, liste de clients, suivi ravitaillement.

👥

Gestion utilisateurs

Création, validation et désactivation des comptes par le CEO et les RH.

Rôles & Accès

6 rôles distincts avec des permissions granulaires selon les responsabilités.

👑 CEO Accès total

  • Supervise l'ensemble des activités
  • Valide / rejette les nouveaux comptes
  • Importe des données en masse
  • Accède à tous les tableaux de bord

📊 Comptable Finance

  • CA total, résultat net, crédits ouverts
  • Suivi paiements, échéances, dettes
  • Commissions agents, validations
  • Analyse produits & promotions

📱 Call Center Groupe 1 Grossistes

  • Commandes grossiste
  • Catalogue produits & producteurs
  • Espace personnel : clients, profil

📱 Call Center Groupe 2 Revendeurs

  • Commandes revendeur
  • Ventes terrain disponibles
  • Espace personnel : clients, profil

🌿 Marketing Analyse

  • Catalogue produits
  • Producteurs & ventes terrain
  • Préparation campagnes

👥 RH Utilisateurs

  • Gestion des comptes utilisateurs
  • Création, modification, désactivation

Stack technique

Architecture moderne fullstack JS avec déploiement cloud.

⚛️

React 18 + Vite

Frontend SPA, routage avec React Router, state global via Context API.

🟩

Node.js + Express

API REST backend, middleware CORS, parsing JSON, gestion des routes par fichier.

🐘

PostgreSQL (Railway)

Base de données de production hébergée sur Railway. Connexion via DATABASE_URL.

🪶

SQLite (local)

Base locale via better-sqlite3. Activée automatiquement sans DATABASE_URL.

🚂

Railway

Hébergement backend + base de données PostgreSQL. Déploiement auto sur push git.

🔐

Authentification

Login par pseudonyme + mot de passe hashé SHA-256. Pas de JWT — session via état React.

Démarrage rapide

Lancer le projet en local en quelques commandes.

💻 En local (SQLite)

Cloner le projet

git clone <repo> && cd agri-dashboard

Installer les dépendances backend

cd backend && npm install

Lancer le backend

npm run dev — SQLite créé automatiquement

Installer le frontend

cd ../frontend && npm install

Lancer le frontend

npm run dev → http://localhost:5173

🚂 En production (Railway)

Créer un projet Railway

Ajouter deux services : backend et frontend

Ajouter PostgreSQL

Railway injecte DATABASE_URL automatiquement

Variables d'environnement

CORS_ORIGIN = URL du frontend Railway

Pousser le code

git push — Railway déploie automatiquement
